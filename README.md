# Code for TMB Paper

This repository contains the scripts used to generate the analyses and figures for:

> **Association of high tumor mutational burden with brain metastases: Insights from a large-scale database analysis**
>
> Marana Abboud, Saumya Sisoudiya, Benjamin Kaplan, Tomer Elisha, Laureen Goodman, Fayhaa Khair, Smruthy Sivakumar, Ethan Sokol, Ido Wolf and Tami Rubinek2
>
> Submitted to Neuro-Oncology

---

## Repository files

Script files:

- `.R` – R scripts for figures 2, 3 and 4A-D
- `.ipynb` – Python Jupyter notebook for figure 4E
- `renv.lock` – R package lockfile


Data files:
```
fig2_data.xlsx
fig3_data.xlsx
data_4B.csv
data_4C.csv
data_4E_MSK_total_samples.csv
data_4E_MSK_MSI.csv
```

The computational environment used for this work is documented in:

- `R_package_versions.md` – summary of the R software environment
- `renv.lock` – detailed R package versions 
- `python_requirements.txt` – Python packages required for the notebook
